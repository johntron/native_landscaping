PATCH NETWORK — PLAT NO. 001 · BLACKLAND PRAIRIE, DFW
§ 1 Geometry § 2 Screen § 3 The Ask Sources

A yard is a plot line.
A neighborhood is a territory.

Bird territories in this ecoregion run 1–2 hectares. No single yard closes that distance. A cluster of participating lots can. This page surveys the geometry of that cluster, screens the plant list against the regional flora, and asks three questions I can't answer alone.

§ 1.03

The ask

three open items, unresolved

This is not a finished proposal. The assumption I'd most like challenged is that a coordinated effort is wanted at all — the questions below are in that order on purpose.

ASK 01

Red-line the screen

The genus table above is a first pass. If a citation is wrong, a species is misidentified, or a "my judgement" row should be rejected outright — mark it up.

ASK 02

Does a chapter yard registry already exist?

If a native-plant chapter is already tracking participating yards in this area, this whole page may be duplicate effort. I'd rather find that out now.

ASK 03

Is there appetite for a coordinated effort at all?

Before geometry, before species lists — do enough people want to plant toward a shared cluster, rather than independently, for this to be worth building?
